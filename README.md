# 🖥️ Mainframe Architecture Simulators  
### Inspired by the IBM Systems Service Structure Course

This project is a collection of **interactive simulators built in HTML, CSS, and JavaScript** designed to help students and professionals understand **IBM Mainframe internal architecture concepts**.

The simulators are inspired by the **IBM Systems Service Structure** course and aim to provide a **visual and interactive learning environment** for mainframe topics that are usually difficult to visualize.

---

# 🎯 Project Goal

The goal of this repository is to create a **didactic and accessible environment** where users can explore core concepts of the IBM mainframe ecosystem.

Instead of only reading theory, learners can **interact with simulations that reproduce internal system behaviors**.

These simulators help illustrate topics such as:

- System Initialization
- Task Management
- Input/Output Processing
- Addressability
- Storage Management
- Recovery and Error Handling
- IPL Troubleshooting

---

# 🧠 Simulators Included

This repository includes several educational simulators:

| Unit   | Topic                                |
| ------ | ------------------------------------ |
| Unit 2 | Operating Environment Initialization |
| Unit 3 | Task Management                      |
| Unit 4 | Input/Output Supervisor              |
| Unit 5 | Addressability                       |
| Unit 6 | Storage Management                   |
| Unit 7 | Recovery Termination Manager         |
| Extra  | IPL Troubleshooting Simulator        |

Each simulator reproduces system messages and behaviors commonly seen in environments such as:

- z/OS system startup
- JES initialization
- task dispatching
- memory management
- ABEND handling
- system recovery routines

---

# ⚙️ Technologies Used

The project is intentionally simple and accessible.

It uses only **web-native technologies**:

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

Advantages of this approach:

✔ No installation required  
✔ Runs directly in the browser  
✔ Easy to modify and extend  
✔ Perfect for training and demonstrations

---

# 📚 Educational Purpose

These simulators were created for:

- Students learning **IBM mainframe architecture**
- Professionals starting in **z/OS environments**
- Training sessions
- Workshops and presentations
- Self-study environments

They are **not emulators** of real IBM systems.

Instead, they are **didactic simulations designed to illustrate internal concepts**.
