Mainframe IPL Simulator

Simulador educacional do processo de Initial Program Load (IPL) em sistemas IBM Z

Sobre o Simulador

Este projeto apresenta um simulador educacional do processo de IPL (Initial Program Load) utilizado em sistemas IBM Z / Mainframe.

O objetivo é demonstrar de forma visual e interativa as etapas fundamentais de inicialização de um sistema operacional como o z/OS.

Durante a execução do simulador é possível observar o fluxo típico de inicialização:

  • Criação e ativação de uma LPAR
  • Inicialização do hardware
  • Carregamento do núcleo do sistema
  • Inicialização do JES2
  • Inicialização do TSO
  • Inicialização do ISPF
  • Inicialização de subsistemas como CICS e DB2
  • Disponibilização do SDSF

Esse processo representa, de forma simplificada, o ciclo de boot de um ambiente real de mainframe.

Para quem este simulador foi criado

  • Estudantes de mainframe
  • Operadores de sistemas IBM Z
  • Administradores de sistemas (Sysprog)
  • Instrutores de treinamento em z/OS
  • Profissionais interessados na arquitetura de mainframes

Limitações do Simulador

Este simulador foi desenvolvido exclusivamente para fins educacionais e não representa um ambiente real de produção.

Algumas limitações incluem:

  • Não executa um sistema operacional real como z/OS
  • Não utiliza hardware IBM Z real
  • As mensagens exibidas são simuladas
  • Não há gerenciamento real de dispositivos ou canais
  • Os subsistemas (JES2, CICS, DB2, SDSF) são representações conceituais

Em um ambiente real de mainframe, o processo de IPL envolve componentes adicionais como:

  • Hardware Management Console (HMC)
  • Perfis de LPAR
  • Volumes de sistema (SYSRES)
  • Subsystems complexos
  • Configuração de dispositivos e canais

Projeto Educacional

Este simulador faz parte das iniciativas educacionais da comunidade Bellacosa Mainframe, com foco na disseminação de conhecimento sobre sistemas IBM Z e tecnologias de missão crítica.

O objetivo é tornar o aprendizado de arquitetura mainframe mais acessível, visual e interativo.
